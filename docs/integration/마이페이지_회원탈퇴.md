# 마이페이지와 회원탈퇴

- 일반 회원: 로그인 → 상단 마이페이지 (`#/mypage`). 본인 정보 조회, 피팅·옷장 이동, 하단 계정 관리에서 탈퇴.
- 관리자: 기존 일반 로그인창에서 환경설정의 관리자 ID·비밀번호로 로그인 → 상단 관리자 (`#/admin`). 가입 통계와 마스킹된 회원 목록 확인. 일반 회원 토큰은 관리자 API에서 403으로 거절된다.
- `GET /api/auth/account`: 로그인한 본인의 아이디·닉네임·연락처·가입일·문자 동의 상태만 반환한다. 해시와 약관 원문 기록은 반환하지 않는다.
- `DELETE /api/auth/account`: Bearer 토큰 및 JSON `password`, `confirmation: "회원탈퇴"` 필요. 계정 ID를 클라이언트에서 받지 않는다. 성공은 본문 없는 204다.
- 본인 프로필·인바디·옷장·시즌 찜·코디 및 코디 항목을 삭제 후 회원을 삭제한다. 존재하는 선택 테이블만 처리한다. 공용 상품 및 다른 회원 데이터는 보존한다. 외래키 등으로 실패하면 409와 함께 전체 롤백한다.
- 새로운 회원 소유 테이블이 추가되면 삭제 순서를 검토하여 `account.py`와 격리 테스트를 보완해야 한다. 현재 구현은 계정을 즉시 삭제하며 별도 탈퇴 유예·복구·법적 보존 기록 정책은 구현하지 않았다.
- 공동 DB의 실제 탈퇴는 수행하지 않았다. 테스트는 전용 메모리 DB와 브라우저 Mock 응답으로 진행했다. 새 DB 스키마 변경은 없다.

관련 테스트 (backend 폴더): `.\.venv\Scripts\python.exe -m pytest tests/test_account.py tests/test_admin_login.py tests/test_auth.py -q`

관련 테스트 (frontend 폴더): `node --test src/services/account.test.js src/services/auth.test.js src/services/authSession.test.js`
