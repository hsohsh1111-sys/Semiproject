# 상품 사이즈표 기반 반팔 비교 1단계 (2026-11-03)

## 구현 수준

**입력 사이즈표의 기준 대비 치수 차이를 반팔 부위별로 반영하는 비교 기능이다. 실제 상품의 절대 cm와 최종 GLB 치수가 일치하도록 보정한 기능은 아니다.** 현재 실제 판매처의 의류 실측표는 확보되지 않았다. 샘플 S/M/L/XL은 사용자가 'UI 검증용 샘플 입력'을 눌렀을 때만 채우며 판매 상품 치수로 표시하지 않는다.

기존 반팔 `ONFIT_TShirt_BodyMorph_v5.glb`, 인체 v3와 6개 의류 Morph Target, 사용자 신체 입력·프린트·카메라 구조를 재사용한다. 원본 BLEND/GLB, Python body/garment 엔진, FastAPI와 TiDB는 변경하지 않는다. 기존 Python garment_engine은 핏별 여유분/고정 기준 계산용이며 상품 실측표 입력 API가 없어 이번 단계에서 재작성하거나 공식을 복제하지 않았다.

## 입력과 출처

상품 키에 연결된 사이즈 행마다 사이즈명·어깨너비·가슴 단면·총장(cm)을 입력한다. 소매는 선택이며 없으면 추정하지 않는다. 판매처 원문 유형은 HTTPS 출처와 원문 입력 확인 체크가 필수다. 신체 권장 사이즈표가 아니라 의류 실측표를 입력하도록 안내한다. 출처는 수동 입력·자동 대조 미완료로 표시한다.

명시적으로 비교 기준 사이즈를 선택한다. 사이즈표·출처·선택 행은 해당 상품의 브라우저 메모리에 연결된다. DB 저장/크롤링/원문 자동 파싱은 하지 않는다. 기존 free-text 실측표도 남기고 자동 숫자 해석은 하지 않는다. 중복명·누락·잘못된 수치와 URL을 거부한다. 기준 또는 선택 소매 값이 없으면 소매 차이는 적용하지 않는다.

기준 대비 어깨 ±8cm, 가슴 단면 ±10cm, 총장 ±15cm, 소매 ±8cm를 현재 시각화 제한 범위로 사용한다. 초과한 실측 행은 보존하지만 선택 변형을 거부하며, 임의로 수치를 줄여 적용하지 않는다. 이 범위 전체의 무관통을 보장하지 않는다.

## 변형 및 비교 방식

`productSizing.js`가 기준 행과 선택 행의 cm 차이를 m로 변환한다. 실제 템플릿 복제 기하에 다음 국소 이동장을 적용한다. 메시 전체 scale은 변경하지 않는다.

- 어깨: 상부 좌우 이동과 소매 시작 영역 이동
- 가슴 단면: 몸통 폭 변화; 3D 둘레가 단면×2와 정확히 일치하는 보정은 아님
- 총장: 목·상부를 유지하면서 아래쪽으로 갈수록 밑단 이동
- 소매: 기준 자세의 팔 방향을 따라 끝부분 길이 차이 반영

매번 원본 좌표에서 계산하여 누적 오차를 막는다. 기존 체형 Morph 변형량과 선택 사이즈는 별도 상태/버퍼다. 기준 행 복원 시 사이즈 오프셋은 정확히 0이 되며 사용자 체형은 유지한다. UV·인덱스·기존 Morph 배열은 보존하고 변경된 크기의 표면 법선을 복제 기하에서 계산한다. 원본 기하와 원본 파일은 수정하지 않는다.

프린트 보조 좌표는 사이즈가 바뀐 rest pose로 갱신한다. 선택 원본 이미지의 가로/세로 비율과 같은 텍스처·uniform을 유지하고, 이후 체형 Morph를 따라 프린트도 움직인다. 극단 체형에서의 천 늘어남과 인쇄 왜곡을 완전히 보정하지는 않는다. 실제 브라우저에서 새 사이즈 전환과 프린트 위치/비율을 확인해야 한다.

비교 정보는 어깨차=의류 어깨-사용자 어깨, 가슴 여유차=가슴 단면×2-사용자 가슴둘레, 총장차=선택-기준으로 표시한다. 평면 실측과 착용 둘레의 차이를 명시하며 추천 사이즈나 착용 가능 판정을 내리지 않는다. 상체 길이 실측이 없으므로 정확한 착용 길이 위치도 추정하지 않는다.

## 검증 결과

- 관련 자동 테스트 **26개 통과**, 프론트엔드 빌드 성공. 표 검증·출처·선택/복원·원본 UV/Morph 보존·실제 Three.js 정점 변화·프린트 유지·기존 카메라 수학을 확인했다.
- `check_product_sizes.mjs`가 실제 Three.js 평가 정점을 내보내고 `inspect_product_sizes.py`가 독립적으로 검사했다. 원본 GLB SHA256 보존을 확인했다.
- 샘플 4사이즈 × 기본/복부 최대·골반 최소 **8조합**에서 사이즈로 추가된 면 법선 역전 0, 자기 교차 0이다. 단, 신체 관통은 남는다.
- 기본 신체의 삼각형 교차 쌍: S 1402 / M 0 / L 37 / XL 226. 최근접 표면 법선 기준 최소 간격은 S 약 -11.1mm / XL 약 -7.5mm다. 이는 정확한 전역 관통 깊이나 착용감 측정이 아니다.
- 복부 최대·골반 최소의 신체 교차: S 1326 / M 0 / L 38 / XL 208. 작은 사이즈뿐 아니라 큰 사이즈에서도 겨드랑이·소매 연결/밑단에 교차가 발생한다. 이를 숨기거나 전신 확대해 해결한 것으로 표시하지 않았다.
- 비교 렌더 **18장**에서 S의 신체 노출과 사이즈별 밑단·소매 변화 등을 확인했다. 렌더는 단색 티셔츠의 기하 검사용이며 실제 프린트 WebGL 표시 검증은 아니다.
- 결과: `assets/blender/previews/product_sizes_v1/validation.json`, 같은 폴더 PNG. Blender의 use_nodes 향후 버전 관련 경고는 있었으나 검사 JSON·18장·완료 마커와 원본 해시 검사를 확인했다.
- 새 사이즈 기능의 브라우저 조작·실제 WebGL 품질 검증은 미완료다. 이전 프린트 기능의 브라우저 정상 동작은 사용자가 확인했다.

## 미구현

실제 상품 절대 치수에 맞춘 GLB 캘리브레이션, 어깨선/암홀/가슴 둘레/총장/소매 랜드마크 검증, 원단 두께·신축성·봉제/주름 및 충돌 해결, 체형 변화 후에도 실측 둘레를 고정하는 재분배, 실제 사이즈 추천은 미구현이다. 향후 치수 전용 Morph Target 또는 제약 기반 변형과 검증된 기준 의류가 필요하다. 현재 부위별 이동장은 이런 정밀 의류 모델의 대체물이 아니다.
