## 최신 적용 버전 — v5

여성형 인체 v2의 가슴 볼륨 변경에 맞춰 5종 모두 `ONFIT_{TShirt,LongSleeve,Pants,Outer,HoodedJacket}_Female_v5.glb`로 다시 제작·연결했다. 원본은 보존했다. 제작/독립 검사 기록은 `female-clothes-v5.json`, `female-clothes-validation-v5.json`, 비교 렌더는 `previews/female_clothes_v5/`다. 관련 테스트는 새 가슴 국소 변화 검사까지 24개 통과했다. 코드 빌드도 성공했다.

기본 체형 인체 교차 쌍은 반팔·긴팔·바지·아우터 0, 후드 집업 186이다. 후드에는 5mm 초과 음수 간격 표본 1개(약 -5.5mm)가 남아 있다. 아우터·후드 자기 교차 후보와 일부 의류 간 겹침도 남아 있어 완전 무관통으로 표시하지 않는다. 브라우저 육안 검증은 미완료다.

아래 표와 v4 수치는 이전 버전의 기록이다.

## 적용 방법

기본 인체와 여성형 인체의 실제 MPFB 정점 차이를 공통 Blender 좌표계에서 계산했다. 기존 의류 표면을 전체 확대·축소하지 않고 인접 인체의 변위장으로 옮겨 여성형 어깨·가슴·허리·골반의 기본 실루엣에 맞췄다. 원래 주름·정점 순서·UV·텍스처·Morph 이름·기본 가중치를 보존했다. 이는 기존 의류의 재피팅이며 새로운 여성복 재단이나 천 물리 시뮬레이션이 아니다.

마른/근육형 의류 Morph는 여성형 인체의 실제 두 타깃을 기준으로 다시 계산했다. 기존 부위별 Morph는 유지했다. 새 변위는 UV 경계에서 중복된 정점끼리 평균을 맞춰 새 틈이 벌어지지 않게 했다. 필요한 근접 영역만 여유분을 보정했고, 후드 집업의 목둘레는 별도로 반복 보정했다.

## 현재 파일

아래 파일은 `frontend/public/models/`에 있다. 대응 편집 원본은 로컬 `assets/blender/`의 같은 이름 `.blend`다.

- `ONFIT_TShirt_Female_v4.glb`
- `ONFIT_LongSleeve_Female_v4.glb`
- `ONFIT_Pants_Female_v4.glb`
- `ONFIT_Outer_Female_v4.glb`
- `ONFIT_HoodedJacket_Female_v4.glb`

기존 기본 인체·의류 GLB는 덮어쓰지 않았다. 이번 작업의 중간 여성 의류 GLB 7개는 `assets/blender/female_clothes_drafts/`로 옮겨 웹 배포 자산에서 제외했다. 여성형 인체 `ONFIT_Human_Female_v1.glb`는 이동하지 않았다.

`garmentGlb.js`의 `getTopGarment`, `getBottomGarment`, `getOuterGarment`가 모델 종류에 따라 의류를 고른다. `FittingPage.jsx`는 착용·색상 상태를 유지하면서 해당 경로를 전달한다. 슬라이더 변경은 Morph 값만 갱신하며 모델 URL을 바꾸지 않는다. 모자는 기존 공용 자산이며 여성형 전용으로 다시 제작하지 않았다.

도구: `prepare_female_clothes.py`, `verify_female_clothes.py`, `render_female_clothes.py`. 원본 해시·형상 제작 기록은 `assets/blender/female-clothes-v4.json`, 내보낸 GLB의 별도 검사는 `female-clothes-validation-v4.json`이다. v1/v2 중간 검사는 최신 결과로 사용하지 않는다.

## 검증 결과와 한계

- 관련 Node 테스트 23개 통과: 실제 GLB의 형상 차이, 위상·UV·내장 이미지 바이트·타깃 이름·기본값, 양방향 및 복합 Morph·복원, 재질 분리, 카메라 회귀를 확인했다. UV 경계에 새 변위 차이가 생기지 않는지도 검사했다.
- Vite 메모리 코드 빌드 성공. 실제 로컬 개발 서버에서 의류 5종 경로가 HTTP 200과 GLB 헤더를 반환하는 것을 확인했다. 이는 브라우저 렌더 검증이 아니다.
- 내보낸 GLB를 Blender에 다시 불러와 기본/마른/근육형/복부 최대·골반 최소/어깨·가슴 최대/허리 최소·엉덩이 최대를 검사했다.

삼각형 쌍 수는 관통 부위 수·깊이가 아니다. 자기 교차 검사에서는 원본 UV 경계의 중복 정점으로 이웃하는 면을 제외했지만 겹·봉제선·접힘의 접촉과 실제 시각적 결함을 모두 구분하지 못한다. 아우터·후드 자체 교차 후보가 없어졌다고 주장하지 않는다.

후드 집업 목둘레의 가장 나쁜 음수 간격 표본은 초기 약 -42.6mm에서 최종 약 -5.6mm로 감소했으나 관통을 완전히 제거하지 못했다. 이는 엄밀한 최대 관통 깊이가 아니다. 허리 최소·엉덩이 최대에서는 긴팔과 인체의 교차 181쌍·음수 표본 15개가 남았다. 모든 연속 체형 조합의 착용을 보장하지 않는다.

기본 레이어링 교차 쌍은 반팔/바지 0, 긴팔/바지 73, 후드/바지 242, 반팔/아우터 0, 긴팔/아우터 0이다. 후드와 패딩의 동시 착용 제한은 유지한다. 의류 경계의 정상적인 겹침과 관통의 시각적 판정은 추가로 필요하다.

Blender 비교 렌더 7장: `assets/blender/previews/female_clothes_v4/`. 기본 반팔+바지의 정면·측면·후면, 긴팔+바지 정면, 반팔+바지+아우터 정면, 후드+바지 정면·측면을 확인했다. 이 렌더 확인은 실제 브라우저 검증이나 극단 체형 렌더 검증을 대체하지 않는다.
