# 여성형 마네킹 v1 — 2026-11-05

## 최신 가슴 볼륨 보정 — v2

- 현재 모델은 `ONFIT_Human_Female_v2.glb`다. v1과 편집 원본을 보존했다.
- 기존 MPFB maxcup 볼륨 가중치를 약 0.0885→0.35로, 가슴 평탄화 보정 가중치는 1→0.5로 조정했다. firmness 타깃은 유지했다. 실제 컵 사이즈나 신체 실측을 의미하는 수치가 아니다.
- 모델 좌표 기준 최대 전방 변화는 약 18.5mm다. 가슴 아래 연결부의 부드러운 변화도 포함하지만 하체·팔·얼굴과 위상은 유지한다. 새 타깃을 추가하지 않아 기존 23개를 유지한다.
- 여성 의류는 같은 기준으로 다시 보정한 `*_Female_v5.glb` 5종을 사용한다. 기존 원본·v1/v4는 보존했다. 모자는 공용 자산을 유지한다.
- 관련 테스트 24개 통과, Vite 메모리 코드 빌드 성공. Blender 정면·측면 인체와 반팔 착용 렌더를 확인했다. 실제 브라우저 시각 검증은 미완료다. 기존 후드 목둘레·극단 체형·레이어링 문제는 완전히 해결하지 않았다.

아래는 최초 v1 제작 당시 기록이다.

- 원본: 로컬 `assets/blender/ONFIT_Human_BodyBuild_v11.blend`. 원본 파일·기본 마네킹 GLB는 덮어쓰지 않았다.
- 여성형은 기존 MPFB의 실제 여성 인종/성별 타깃을 사용한다. 각 인종의 남녀 혼합 가중치 합을 보존하면서 여성형으로 설정했다. 남성 모델을 단순 복사해 이름만 바꾼 자산이 아니다.
- 마른/근육형은 MPFB의 여성용 macro target으로 별도 제작했다. 근육형의 남성 전용 복근 표현은 적용하지 않는다. 실제 개인 신체 복원이나 성별 판정 기능은 아니다.
- 출처: MPFB core targets, CC0. 기존 [체형 자산 기록](./body_builds.md)의 원본 출처를 따른다. 공식 라이선스 안내: https://static.makehumancommunity.org/mpfb/faq/can_i_sell_models.html
- 제작 도구: `frontend/scripts/create_female_mannequin.py`.
- 출력: `assets/blender/ONFIT_Human_Female_v1.blend`, `frontend/public/models/ONFIT_Human_Female_v1.glb` 및 제작 JSON.
- 기존 정점 순서·23개 Morph Target 이름·UV·기본 자세를 유지한다. 여성형 성별 가중치와 여성용 체형 2개는 의도적으로 변경했다.
- 최초 연결 시에는 기본 마네킹 의류를 공용으로 사용했다. 이후 반팔·긴팔·바지·아우터·후드 집업의 여성형 보정본을 별도로 제작해 연결했다. 모자는 기존 공용 자산을 유지한다. 최신 경로·검사·제한은 [여성형 의류 보정 기록](./female_clothes.md)을 참고한다. 최종 브라우저 실루엣·관통 검증은 미완료다.
- 의류·색상 초기화는 모든 의류를 벗기고 상의 화이트/나머지 기본 재질로 되돌린다. 사용자 지정 색상 입력과 상품 적용 상태도 초기화한다. 선택한 마네킹·체형 치수·카메라 회전·확대는 유지한다.
