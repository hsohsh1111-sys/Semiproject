# 반팔 상품 치수 보정 v3

2026-11-03. UI 검증용 샘플이며 판매 상품 실측·추천 정확도 검증이 아니다.

## 원인과 변경

기존 방식은 원본 MPFB 형상을 입력한 기준 M과 동일하다고 가정하고 사이즈 간 차이만 적용했다. 원본 기준점 측정은 어깨 36.4527, 가슴 단면 대용값 45.1801, 총장 58.3346, 소매 17.0460cm여서 M 입력 44/52/68/21과 차이가 있었다. 신체용 의류 Morph를 함께 적용하면 상품 공칭 치수도 변했다.

`productSizing.js`에서 원본 좌표에 부위별 변위장을 적용하고 네 측정 목표를 유한차분 Jacobian과 반복 풀이로 보정한다. 전체 모델 일괄 스케일은 사용하지 않는다. 수렴 실패 시 이전 형상을 유지하고 UI에 실패를 표시한다. 기준 사이즈 선택은 비교용이며 보정 결과를 결정하지 않는다. 소매 미입력은 원본 기하 길이를 유지한다.

상품 사이즈 적용 중인 반팔만 의류 체형 Morph를 기본 가중치로 유지한다. 신체 및 나머지 의류의 Morph는 계속 적용된다. 작은 옷을 신체에 맞춰 자동 확대하지 않는다. 총장 증가에 따른 뒤밑단 드레이프를 제한적으로 보완했다. 법선 기반 보정 실험은 교차가 증가해 채택하지 않았다.

## 단위와 측정 한계

기존 BLEND는 METRIC, scale_length=1, 관련 객체 scale=(1,1,1)이다. GLB 원본 로컬 좌표 1m=100cm로 측정하고 React 화면 정규화 배율과 구분한다. Blender Z-up과 GLB Y-up의 축 전환을 검증 도구에서 반영한다.

- 어깨: 원본 형상에서 선정한 좌우 어깨 정점 사이 3D 직선.
- 가슴 단면 대용값: 원본 y=1.17m의 닫힌 몸통 링을 추적해 변형 후 둘레÷2. 평면으로 편 실제 가슴 단면과 같다고 검증하지 않았다.
- 총장: 목옆 기준 정점에서 앞밑단 정점까지 수직 투영 거리.
- 소매: 어깨 기준 정점에서 소매끝 정점까지 직선. 봉제선 곡선 길이가 아니다.

Bounding Box를 실측값으로 사용하지 않는다. 기준점은 가까운 정점으로 정한 대용점이며 실제 패턴 봉제선과의 대응은 미검증이다. 같은 측정 함수를 보정 목표와 결과에 사용하므로 작은 오차가 독립적인 실물 정확도 증거는 아니다.

## 샘플 입력 / 측정 / 오차 (cm)

순서: 어깨 / 가슴 단면 대용값 / 총장 / 소매.

| 사이즈 | 입력 | 측정 (소수 둘째 자리) | 네 항목 최대 절대 오차 |
|---|---|---|---|
| S | 42 / 50 / 66 / 20 | 42.00 / 50.00 / 66.00 / 20.00 | <0.01 |
| M | 44 / 52 / 68 / 21 | 44.00 / 52.00 / 68.00 / 21.00 | <0.01 |
| L | 46 / 54 / 70 / 22 | 46.00 / 54.00 / 70.00 / 22.00 | <0.01 |
| XL | 48 / 56 / 72 / 23 | 48.00 / 56.00 / 72.00 / 23.00 | <0.01 |

M의 기존 오차 -7.55/-6.82/-9.67/-3.95cm가 위 대용 측정 기준에서 각각 절대값 0.01cm 미만으로 감소했다. 원시 정밀값은 검증 JSON에 있다.

## 관통·렌더 검사

최종 채택 형상: `assets/blender/previews/product_sizes_v3_final/validation.json` 및 24개 비교 PNG. Blender 검사에서 자기 교차·사이즈 변형에 의한 법선 반전은 8개 상태 모두 0이다. BVH 삼각형 교차 쌍 수는 관통 부위 수나 깊이가 아니다.

| 상태 | 인체/의류 교차 쌍 |
|---|---:|
| S 기본 | 0 |
| S 복부 최대 | 246 |
| S 가슴 최대 | 205 |
| M 기본 | 25 |
| L 기본 | 133 |
| XL 기본 | 231 |
| XL 어깨 최대 | 174 |
| XL 복부 최대 | 455 |

총장 확장으로 좁은 뒤밑단이 엉덩이 영역에 내려오는 문제를 완전히 해결하지 못했다. 복부 극단값에서는 약 5cm 수준의 음수 근접 표본 간격이 남는다. 이는 정점 표본 검사이며 엄밀한 최대 관통 깊이가 아니다. 치수 여유가 양수여도 패턴·자세·형상 차이로 관통할 수 있다. 과거 신체에 따라 옷을 확대하던 결과와 현재 고정 상품 크기의 교차 수를 직접 성능 비교하지 않는다.

M 측면 렌더에서 전신 및 늘어난 밑단을 확인했으나 드레이프가 여전히 단순하다. 브라우저 육안 검증, 실제 상품과의 비교, 원단 물리·착용감 검증은 미완료다. 관통을 숨기거나 옷을 강제로 늘리지 않는다.
