# 상품 사이즈 측정·관통 보정 v2 (2026-11-03)

## 단위와 측정 기준

기존 `ONFIT_TShirt_BodyMorph_v5.blend`를 읽어 METRIC, scale_length=1.0, 티셔츠·인체 객체 scale=(1,1,1)을 확인했다. 원본에 저장하지 않았다. 검사 파일은 `assets/blender/previews/product_sizes_v2_units.json`이다. 시작 시 MPFB 로그 폴더 권한 경고는 있었지만 단위/객체 데이터 읽기는 완료됐다. 이 검사에는 애드온 실행이 필요하지 않았다.

로컬 glTF Y-up(Blender Z-up)의 모델 단위 1을 1m로 해석해 cm로 환산한다. 화면의 인체 중앙배치/높이 정규화 배율은 별도이며, 사용자 입력 키·가슴둘레가 모델에서 물리적으로 보정됐다는 의미가 아니다.

판매처 봉제선과 대응하는 랜드마크가 없어 다음은 모두 **기준점 대응 미검증 추정치**다. Bounding Box로 의류 실측을 대신하지 않는다.

| 항목 | 측정 기준 |
| --- | --- |
| 어깨 | 원본 좌우 어깨 표면 기준점 간 3D 직선 거리 |
| 가슴 단면 | 원본 y=1.17m의 겨드랑이 아래 몸통 링을 삼각형/평면 교차로 추출, 변형 후 재평가한 3D 둘레÷2. 하나의 닫힌 링인지 검사하며 실패하면 측정 불가 |
| 총장 | 원본 목옆 높은 기준점에서 앞밑단 기준점까지 수직 투영 길이 |
| 소매 | 오른쪽 어깨 기준점에서 오른쪽 소매 끝 기준점까지 3D 직선 |

선택 사이즈와 체형 Morph가 적용된 실제 Three.js 정점을 측정해 UI에 입력값/3D 추정/차이(cm)를 표시한다. 어깨 봉제선 호길이, 평평하게 놓인 가슴 단면, 곡면을 따라 잰 총장·소매와 동일하다고 검증하지 않았다.

## 기본 체형: 샘플 입력 → 최종 모델 추정 (cm)

실제 상품 표가 아니며, 이전과 동일한 명시적 UI 샘플을 사용했다. 괄호는 `추정−입력`이다.

| M | 44 → 36.45 (-7.55) | 52 → 45.18 (-6.82) | 68 → 58.33 (-9.67) | 21 → 17.05 (-3.95) |

기준 대비 변화는 어깨·총장 약 2cm, 소매 약 1cm를 재현하지만 가슴 단면 변화는 입력 2cm당 약 2.5cm로 차이가 남는다. 기준 M의 절대 오차를 감추거나 추정 기준점을 실제 봉제선으로 간주해 강제로 보정하지 않았다. 정확한 절대 치수 피팅은 미완료다.

## 실제 수정

- 기존 소매 이동 방향 (.85,-.53)은 원본 어깨→소매 끝 방향과 달랐다. 약 (.65,-.76)으로 변경했다.
- 큰 어깨값에서 소매 전체를 아래로 평행이동하면 어깨 윗면이 신체로 들어가므로 그 후보는 폐기했다. 최종은 말단 소매만 어깨 기준점 주변에서 완만하게 회전한다.
- 가슴 변형의 상단을 낮춰 어깨 기준점으로 퍼지지 않게 하고, 측면 이동을 좁은 겨드랑이에 집중시키지 않도록 몸통 전후 두께에도 일부 분산했다.
- 총장/소매 전이부를 부드럽게 연결했다. 전신 scale 변경·관통 숨김·작은 사이즈 자동 확장은 하지 않았다.
- UV·프린트 소유권·원본 GLB·기존 인체/의류 Morph·색상·카메라 구조는 유지했다. 실시간 측정 callback은 동일 결과를 재설정하지 않아 상태 갱신 루프를 방지했다.

## 요청한 8조합 검사

실제 Three.js 최종 정점을 Blender BVH로 검사했다. 교차 쌍 수는 관통 깊이나 착용 정확도와 동일하지 않다.

| 조합 | 신체 교차 쌍 | 근접 표면 법선 기반 최소 간격(추정) |
| --- | ---: | ---: |
| S 기본 | 1317 | -13.08mm |
| S 복부 최대 | 1206 | -11.31mm |
| S 가슴 최대 | 1384 | -13.09mm |
| M 기본 | 0 | +3.85mm |
| L 기본 | 0 | +0.82mm |
| XL 기본 | 123 | -4.24mm |
| XL 어깨 최대 | 121 | -3.75mm |
| XL 복부 최대 | 119 | -4.11mm |

모든 8조합에서 사이즈로 추가된 면 법선 역전·자기 교차는 0이다. 동일 기본 체형 비교에서 L 교차는 37→0, XL은 226→123, XL 최소 간격은 약 -7.54→-4.24mm로 개선됐다. S 교차 수는 1402→1317이지만 최소 간격은 약 -11.11→-13.08mm로 악화된 부분이 있어 **S의 관통이 해결됐거나 모든 지표가 개선됐다고 볼 수 없다**. 작은 사이즈를 늘려 숨기지 않았고 음수 입력 여유분 경고·모델의 시각적 한계를 표시한다.

최종 검사: `assets/blender/previews/product_sizes_v2_verified/validation.json`, `states.json`, PNG 24장. 중간 후보 `product_sizes_v2`, `product_sizes_v2_final`은 비교용으로 보존했다. Blender 단색 렌더에서 L/XL 기본의 형태를 확인했다. 새 프린트 동시 표시와 브라우저 조작의 육안 검증은 미완료다.
