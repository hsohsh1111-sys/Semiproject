# 반팔 상품 디자인 수동 적용 (2026-11-03)

## 구현 범위

기존 `ONFIT_TShirt_BodyMorph_v5.glb` 반팔 1종을 재사용한다. 기존 상품 비교 패널에서 상품 앞면 이미지 또는 권한이 있는 로컬 PNG/JPEG/WEBP(10MiB 이하)를 사용한다. 원본 GLB·Python 엔진·FastAPI·DB·다른 팀원 코드는 변경하지 않는다.

- `ProductDesignEditor.jsx`: 이미지에서 드래그 또는 x/y/너비/높이 슬라이더로 디자인 영역 선택. 초기 사각형은 안내용이며 자동 로고 검출 결과가 아니다.
- 원단 배경색을 직접 입력하거나 이미지에서 찍고, 그 색상과의 RGB 거리로 배경을 투명하게 제거한다. 제거 강도와 사용 여부를 조절하고 마지막 적용 결과를 확인할 수 있다. 어두운 로고나 사진의 그림자도 제거될 수 있다.
- 이미지 사용·수정 권한 확인 체크 후 적용한다. 로컬 이미지와 선택 상품이 동일하다고 검증하지 않으며, 제공된 나이키 사진의 판매처 ID·구매 링크·상업적 재배포 권한은 여전히 미확인이다.
- 외부 이미지가 CORS를 허용하지 않으면 픽셀 처리를 중단하고 로컬 파일 안내를 표시한다. 차단을 우회하는 프록시나 임의의 대체 이미지는 사용하지 않는다. 입력은 브라우저 메모리 안에서만 처리한다.

## 3D 적용 방식

원본 반팔은 16,014개 UV 정점과 Morph Target 6개를 가진다. 기존 UV는 MPFB 고유 텍스처용이라 사진 전체를 그대로 씌우지 않는다. 실제 메시의 원래 좌표·법선을 검사하여 앞판을 구분하고, 원본 UV를 유지한 별도의 **앞판 프린트 보조 좌표**를 런타임 복제 기하에 추가한다. 별도의 떠 있는 로고 메시를 생성하지 않는다.

`productAppearance.js`의 복제 재질에만 PBR 셰이더 확장을 적용한다. 선택한 CanvasTexture의 RGB·알파를 원단 기본색 위에 합성하고 이후 원단 조명을 받게 한다. 앞면 법선·앞쪽 z·중앙 몸통 범위·`gl_FrontFacing`을 검사하여 뒤판·소매·안쪽 면에 표시되지 않게 제한한다. 상품의 기본 HEX 색상과 다른 의류 재질은 유지한다.

프린트 위치와 너비만 조절하며 높이는 선택 이미지 비율로 계산한다. 앞판 범위는 템플릿 좌표 x -0.15~0.15m / y 1.03~1.37m, 너비 최대 0.26m / 높이 최대 0.28m이다. 이는 해당 GLB 기준의 시각적 배치이며 실제 상품 인쇄 치수의 측정값이 아니다. 프린트 좌표가 원래 메시 정점에 붙어 있으므로 실제 Morph 변형을 따라간다. 극단적인 체형에서의 천 늘어남·로고 왜곡을 완전히 보정하는 기능은 없다.

위치·너비 변경은 같은 텍스처/재질의 uniform만 갱신하며 GLB를 다시 요청하지 않는다. 기존 카메라 구조는 변경하지 않는다. 디자인 제거·상품 변경 시 복제 기하/재질과 소유 텍스처를 정리하고 원본 리소스는 보존한다.

## 검증

- 관련 자동 테스트 **24개 통과**: crop/색상 키/빈 추출 오류, 원본 비율과 앞판 경계, UV·인덱스·Morph 배열 보존, 실제 반팔 앞/뒤 정점 마스크, 실제 Morph 정점 변화와 프린트 좌표 유지, Three.js 표준 셰이더 삽입·uniform 갱신/제거, 기존 상품 연결·재질·카메라 회귀.
- 프론트엔드 빌드 성공. 기존 큰 번들 경고는 유지한다.
- 실제 사용자 참조 PNG에서 수동 선택한 111×59 영역을 같은 crop 코드로 처리했다. 흰 스우시/파란 글자와 투명 배경을 확인했다. 위치는 자동 인식 결과가 아니다.
- 로컬 QA 출력: `assets/blender/previews/product_design_v1/selected_design_preview.png`, `crop_validation.json`. `decode_product_design_reference.py`와 `check_product_design_reference.mjs`로 생성했다. 공개 모델 디렉터리에 새 로고 자산을 배포하지 않았다.
- **브라우저 연결 호스트가 없어 실제 WebGL 화면·GPU 셰이더 컴파일·마우스 조작·CORS 실패 시나리오의 육안 검증은 미완료다.** Node 셰이더 문자열 테스트와 빌드는 GPU 렌더 성공을 증명하지 않는다.
